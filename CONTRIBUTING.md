# Contributing

This is a small fork that I maintain on my own, and it's in a quieter maintenance mode. I keep it working and fix what breaks, but I'm not adding much.

Please open an issue before sending a PR. I'm picky about the codebase and its style, and a surprise PR that doesn't fit will likely be closed, which wastes your time.

If you want to help keep it up to date, open an issue first and we can agree on workflow and style before any code is written.

Bugs and questions are welcome as issues. Security problems go through [the security policy](.github/SECURITY.md).
